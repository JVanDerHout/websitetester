# {% include icon.html icon="fa-solid fa-envelope" %} RSVP

We have set up the RSVP form so you can RSVP early if you would like, but know that there is no obligation to RSVP at this time. We will be sending out invitations at a later date and will be requesting your RSVP by March 1st 2027. <br>
